# Grand Theatre – Interactive Ticket Booking System

## Project Description
Grand Theatre is an interactive theatre ticket booking website developed using HTML, CSS, and JavaScript. Users can explore the seating map, select seats, and manage tickets through a shopping cart.

## Main Features
- Dynamic seating map with 224 seats.
- Three seating categories: VIP, Premium, and Standard.
- Different ticket prices for each category.
- Interactive seat selection and ticket details.
- Add and remove tickets from the shopping cart.
- Automatic total price calculation.
- Duplicate booking prevention.
- Unavailable seats.
- Zoom and directional navigation controls.
- Cart data saved using localStorage.
- Responsive layout.

## Technologies
- HTML5
- CSS3
- JavaScript
- localStorage

## How to Run
1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using a browser or Live Server.

## Project Structure
- `index.html` – Main webpage.
- `css/style.css` – Styling and responsive layout.
- `js/data.js` – Seating data.
- `js/app.js` – Seat generation, selection, and zoom controls.
- `js/cart.js` – Shopping cart and localStorage.
- `js/navigation.js` – Section navigation.
